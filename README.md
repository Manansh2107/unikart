# Unikart

Unikart is a Java-based multi-vendor marketplace designed for college students and everyday essentials.

# Project Overview

The platform allows customers to browse and purchase products from Unikart and independent sellers.

# User Roles
- Customer
- Seller
- Admin

# Technology Stack
- Java
- MySQL
- JDBC
- Maven
- Git and GitHub
